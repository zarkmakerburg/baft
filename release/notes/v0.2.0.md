## BAFT v0.2.0

Signed release. Verify before use: `baft-release verify -dir <download dir> -root-pub release/keys/root.pub -revocations release/keys/revocations.json`. `install.sh` does this itself and refuses anything that does not verify. `LICENSE`, `COPYRIGHT` and `THIRD_PARTY_LICENSES.md` are attached to this release and included in the offline bundle.

### Reliability fixes

- **Recovery no longer loses the logical session on a carrier error (P0-R1, #60 #64 #76).** Physical sender and write errors on recoverable sessions are classified as carrier loss; recovery activation is serialized against session teardown; a pre-existing FIN_ACK rollback that could pin recovery in a permanent `STATE_MISMATCH` loop is fixed (churn stress went from 13–15 failures per 200 runs to 0/250).
- **No more multi-second to minute-long Flow stalls on local targets (COR-T1, #77).** Application-facing TCP connections now use fixed kernel buffers; under receive-buffer autotuning, BAFT backpressure could make the kernel drop loopback segments and fall into RTO backoff. COR-01 A/B on CI: about 25% of runs stalled before, 0/43 after.

### New

- **Transactional certificate rotation** (#59): prepare, distribute, verify, atomic activate, confirm, hold and retire, with ordered rollback and per-node evidence.
- **Rerunnable installer** (#57): inspect, plan, apply, verify, roll back. **One-line install** is documented in the README.
- **Safe uninstall** (#58): ownership-proven, journaled and recoverable.
- **Signed offline installation bundle** (#48) and a **release acceptance script** bound to the tag commit (#50).
- **BCC**: web hardening with security headers, request IDs, login limiters and Argon2id (#44); layered health with hysteresis and aligned alerts and webhooks (#53 #54); restore preview (#52), a bounded admin restore preview (#62) and an **offline local restore CLI** `baft-bcc restore` (#63).
- **Tunnels**: plan preview, observed-state verification and generations (#45); ownership markers (#46); drift detection (#47); report-only discovery of existing tunnels (#55).
- **Operator tools**: `baft doctor` v2 (#51) and the `baft menu` with the gold/black header (#56).
- **Third-party license notices** ship with every release, and CI rejects strong-copyleft dependencies (#78).

### Upgrading

Re-run `install.sh` on each server with the same flags as before (`--agent-only` for enrolled servers). It verifies the release, and the anti-rollback state accepts v0.2.0 over v0.1.x. Update IR and EX together so both sides carry the recovery and COR-T1 fixes.

### Not included

Production readiness is not declared. Field detectability measurements (R-003) and the WAN throughput work on larger flow windows (Stage E) are still in progress.
