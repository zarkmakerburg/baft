## BAFT v0.1.1

Signed release. Verify before use: `baft-release verify -dir <download dir> -root-pub release/keys/root.pub -revocations release/keys/revocations.json`. `install.sh` does this itself and refuses anything that does not verify. The signed draft release is generated by the release workflow after the `v0.1.1` tag is pushed.

### New since v0.1.0

- **Native tunnel builder.** BCC builds an IR/EX tunnel between two enrolled servers (`POST /api/tunnels`): prepare both ends, install, health check, finalize. Any failure, timeout or operator cancel rolls both sides back to their previous config and service state.
- **Server inventory and SSH bootstrap.** BCC pins a server's SSH host key and installs `baft-agent` over SSH. SSH credentials live only in memory for the request and are never stored, logged or audited.
- **Dashboard.** New "Add a server over SSH" and "Tunnels" cards.
- **Agent.** Tunnel actions with strict parameter patterns; pairing secrets are returned only in the ack of the step that produced them and wiped from BCC afterwards. The BCC state database now overwrites deleted rows.
- **Retired:** `enroll_peer` and `/api/enroll` (replaced by the tunnel builder; the endpoint answers `410 Gone`).
- **Tests and CI:** end-to-end on systemd with real traffic through a built tunnel and a failed change rolled back (`e2e-launch1`); SSH bootstrap against a real sshd (`e2e-ssh-bootstrap`); weekly `govulncheck`.

### Upgrading

Re-run `install.sh` on each server (`--agent-only` for enrolled servers, with the same flags as before): it verifies the release and the anti-rollback state accepts v0.1.1 over v0.1.0. The `update_baft` job replaces `baft` and `baft-pair` only, not `baft-agent` itself, and an agent installed by v0.1.0 does not have the tunnel actions, so update the agents this way before building tunnels. The new agent unit also gets write access to the BAFT config and state directories.

### Not included

Traffic-level checks inside BCC beyond "service up and listening", and a stable client-facing API contract; both are later work.
