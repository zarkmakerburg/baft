# Stage E Reference Harness

Measurement-only helper for D-001A item 4. No production BAFT code is changed.

Pinned reference versions for the first comparison set:

- FRP: v0.71.0
- Rathole: v0.5.0
- Xray-core: v26.3.27

The shared application workload is generated by `driver.py` against the same echo target. Each tunnel exposes a local ingress port; tc netem is attached only to that tunnel's outer carrier port.

Default WAN comparison payload:

- 8 concurrent flows
- 1 MiB application payload per flow
- 3 repeats/profile
- exact same echo target
- exact same RTT/loss/rate matrix as Stage E WAN measurement

Reference software versions, release asset digests when published, exact config files and process logs are retained with the benchmark artifact.

This harness must not be interpreted as an evasion ranking. It measures performance/resource behavior under controlled impairment only.
