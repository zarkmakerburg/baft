# HQ — آزمون اتصال مستقیم سرورهای واقعی، ۶ اکتبر ۲۰۲۶

**نتیجه: اتصال مستقیم پذیرفته نشده است. مسیر عملیاتی بافت روی حامل کمکی SSH حفظ شده است.**

این گزارش فقط مشاهدات میدانی را ثبت می‌کند؛ علت دقیق اختلال یا عامل آن اثبات نشده است. هیچ release، tag یا merge انجام نشد و Record Shaping تغییر نکرد.

در آزمون Noise مستقیم، شمارنده initiator برابر read=0 و written=98 بود. کنترل همان ابزار، همان کلیدها و همان مرجع اعتماد روی مسیر کمکی برابر read=50 و written=98 و authentication موفق بود. موفقیت Noise-only با موفقیت session یا ترافیک نهایی یکسان نیست؛ ترافیک واقعی مسیر کمکی در گزارش‌های پیشین #67 با پاسخ HTTPS 200 تأیید شده است.

دو تلاش نخست namespace به علت آماده‌سازی ناموفق بودند: دسترسی به پوشه config با حذف capabilityها و سپس مجوز executable برای UID بافت. این دو تلاش شاهد شبکه نیستند. آزمون معتبر با UID/GID بافت و executable فقط خواندنی/اجرایی انجام شد.

## منبع و تمامیت ابزار

منبع در شاخه field/hq-live-noise-20261006 ثبت شده است:

- 25fa63a: مقایسه تنظیمات socket.
- 0df88f0: سرویس و کلاینت bounded WS echo.
- 157c87d: مقایسه بافر دریافت.

باینری‌های میدانی قبل از اجرا با SHA-256 بررسی شدند. ابزار اندازه‌گیری socket برای ثبت همه حالت‌ها exit صفر می‌دهد؛ authenticated=false همچنان FAIL است. exit صفر ابزار، موفقیت اتصال محسوب نمی‌شود.

## وضعیت پس از آزمون

- سرویس اصلی بافت هر دو سمت فعال و NRestarts=0 مشاهده شد.
- ورودی ایران 57163 همچنان به ورودی loopback بافت و مقصد Xray در PNL متصل است.
- carrier این مسیر هنوز SSH است؛ موفقیت native ادعا نمی‌شود.
- unitهای echo، SNI و artifact متوقف شدند؛ پورت‌های آزمایشی 9443، 9445 و 9446 دیگر listener نداشتند.
- forwardهای موقت انتقال artifact بسته شدند. باینری اصلی بافت جایگزین نشد.
- حذف Backpack از هر دو سرور پابرجاست.

## مانع باز و ادامه لازم

شواهد فقط خرابی authentication بافت را نشان نمی‌دهند: WS بدون Noise نیز داده را تحویل نداد و HTTP معمولی انتقال کامل نداشت. تنظیمات محدود TCP و namespace جدا این رفتار را اصلاح نکردند. در بازبینی قبلی قواعد محلی nft و capture هم‌زمان، قاعده‌ای منطبق با حذف داده/ACK این اتصال‌ها دیده نشد و بخشی از بسته‌های خروجی در capture ورودی همتا ظاهر نشد.

پیگیری لازم، بررسی هم‌زمان تحویل داده و ACK در مسیر WAN و شبکه ارائه‌دهندگان این دو IP است. نسبت دادن علت به ISP، فیلترینگ، Backpack یا خود بافت بدون شاهد تکمیلی مجاز نیست. تا پاس شدن ترافیک واقعی مستقیم و آزمون پایداری، حامل کمکی حذف نمی‌شود.
