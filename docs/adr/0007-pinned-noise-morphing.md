# ADR-0007 — حالت صریح Noise با کلید pin‌شده

وضعیت: پیاده‌سازی آزمایشی برای بررسی R3.1 طبق مأموریت فعلی کاربر.

در نبود بخش noise، قرارداد mTLS قبلی فعال می‌ماند. حالت جدید از TLS 1.3 با اعتبارسنجی سرور و Noise IK با کلیدهای pin‌شدهٔ دوطرف استفاده می‌کند. بازدیدکنندهٔ عادی بدون گواهی کلاینت صفحهٔ HTML می‌بیند؛ فقط peer دارای کلید معتبر به Session وارد می‌شود. این تغییر، حالت احراز هویت صریح است و downgrade خودکار ندارد.

هر کلید به یک هویت مجاز نگاشت می‌شود. HELLO منبع اعتماد نیست؛ allowlist مسیر و لغو هویت برقرار است. لغو serial/fingerprint گواهی کلاینت مختص حالت mTLS است. TWRL، PADL و ECRL تغییر نمی‌کنند. نسخهٔ shaping داخل prologue احراز هویت می‌شود.
